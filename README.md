# ESignJr iOS App

An iOS application for digital signature management.

## Project Structure

```
ESignJr/
├── AppDelegate.swift          # App lifecycle
├── SceneDelegate.swift        # Scene management
├── Info.plist                 # App configuration
├── LaunchScreen.storyboard    # Launch screen UI
├── Models/                    # Data models
├── Views/                     # Reusable UI components
├── ViewControllers/           # Screen controllers
├── Services/                  # Business logic & API
├── Utilities/                 # Helper functions
└── Resources/
    └── Assets.xcassets/       # Images and icons

ESignJr.xcworkspace/           # Workspace configuration
ESignJr.xcodeproj/             # Xcode project
```

## Requirements

- iOS 14.0 or later
- Xcode 14.0 or later
- Swift 5.7+

## Getting Started

1. Clone the repository
2. Open `ESignJr.xcworkspace` in Xcode
3. Select the ESignJr target
4. Build and run on simulator or device

## Build Settings

- **Minimum Deployment Target**: iOS 14.0
- **Swift Version**: 5.7
- **Supported Orientations**: Portrait (iPhone), All (iPad)
